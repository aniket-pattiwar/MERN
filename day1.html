What is the MERN Stack?

The MERN stack is a popular and powerful collection of technologies used to build full-stack web applications.

  • MongoDB: A NoSQL, document-based database.
  • Express.js: A back-end web application framework for Node.js.
  • React: A front-end JavaScript library for building user interfaces.
  • Node.js: A back-end JavaScript runtime environment that runs code on the server.

Together, these components allow you to build a three-tier architecture (frontend, backend, database) entirely with JavaScript and JSON.

Relational (SQL) vs. NoSQL Databases

Relational Databases (e.g., MySQL, PostgreSQL)

  • Data is stored in tables with rows and columns.
  • A strict schema defines the table structure, data types, and relationships.
  • Uses SQL (Structured Query Language).

NoSQL Databases (e.g., MongoDB, Cassandra, Neo4j)

  • Data can be stored in various formats like document (JSON-like), key-value, graph.
  • Flexible or dynamic schema allows for storing varied data structures.
  • Built for scalability and high performance.

MySQL databases → use SQL
SELECT * FROM users WHERE age > 25;

MongoDB → uses MQL (JSON-style queries)
db.users.find({ age: { $gt: 25 } })

Run in mongosh 
// mongosh_crud_demo.js - Complete runnable script for mongosh
use schoolDB;

// 1. Create (Insert Documents)
db.students.insertOne({ name: "Alex Kumar", course: "MERN", score: 92, enrolled: true });

db.students.insertMany([
  { name: "Priya Sharma", course: "React", score: 88, enrolled: true },
  { name: "Rohan Verma", course: "Node.js", score: 76, enrolled: false },
  { name: "Sneha Patel", course: "MERN", score: 95, enrolled: true }
]);

// 2. Read (Find with filter and projection)
print("=== High Scoring MERN Students ===");
db.students.find(
  { course: "MERN", score: { $gte: 90 } },
  { name: 1, score: 1, _id: 0 }
);

// 3. Update (Modify record)
db.students.updateOne(
  { name: "Rohan Verma" },
  { $set: { enrolled: true, score: 82 } }
);

// 4. Count & Verify
print("=== Total Enrolled Students ===");
db.students.countDocuments({ enrolled: true });
How it works: Runs all four CRUD operations inside MongoDB: insertOne and insertMany to write records, find() with query projection to fetch data, and updateOne() with $set operator.
