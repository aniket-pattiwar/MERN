Library App Frontend

1. Setup & Dependencies

Create the frontend to consume Library API. Use Vite, Axios for API calls, and Bootstrap for styling.

npm create vite@latest

npm install axios react-router-dom bootstrap

Add Bootstrap in main.jsx:

import 'bootstrap/dist/css/bootstrap.min.css';

2. Book List Component

Create components/BookList.jsx to fetch and display books.


const BookList = () => {
    const [books, setBooks] = useState([]);

    useEffect(() => {
        fetchBooks();
    }, []);

    const fetchBooks = async () => {
        try {
            const res = await axios.get('http://localhost:5000/api/books');
            setBooks(res.data);
        } catch (err) {
            console.error("Error fetching books:", err);
        }
    };

    const handleDelete = async (id) => {
        if(window.confirm('Are you sure you want to delete this book?')) {
            try {
                await axios.delete(`http://localhost:5000/api/books/${id}`);
                fetchBooks(); // Refresh list after delete
            } catch (err) {
                console.error("Error deleting book:", err);
            }
        }
    };

    return (
        <div className="container mt-4">
            <h2 className="mb-4">Library Books</h2>
            <div className="row">
                {books.map(book => (
                    <div className="col-md-4 mb-4" key={book._id}>
                        <div className="card h-100 shadow-sm">
                            {book.coverImage && (
                                <img 
                                    src={`http://localhost:5000/${book.coverImage}`} 
                                    className="card-img-top" 
                                    alt={book.title} 
                                    style={{height: '250px', objectFit: 'cover'}} 
                                />
                            )}
                            <div className="card-body">
                                <h5 className="card-title">{book.title}</h5>
                                <h6 className="card-subtitle mb-2 text-muted">By {book.author}</h6>
                                <p className="card-text small">ISBN: {book.isbn}</p>
                                <button className="btn btn-danger btn-sm" onClick={() => handleDelete(book._id)}>Delete</button>
                            </div>
                        </div>
                    </div>
                ))}
            </div>
        </div>
    );
};

3. Add Book Form (with File Upload)

Create components/AddBook.jsx to handle form data and image upload.

import React, { useState } from 'react';
import axios from 'axios';
import { useNavigate } from 'react-router-dom';

const AddBook = () => {
    const [formData, setFormData] = useState({ title: '', author: '', isbn: '' });
    const [file, setFile] = useState(null);
    const navigate = useNavigate();

    const handleChange = (e) => {
        setFormData({ ...formData, [e.target.name]: e.target.value });
    };

    const handleFileChange = (e) => {
        setFile(e.target.files[0]);
    };

    const handleSubmit = async (e) => {
     e.preventDefault();
 
     try {
         const data = new FormData();
 
         data.append('title', formData.title);
         data.append('author', formData.author);
         data.append('isbn', formData.isbn);
 
         if (file) {
             data.append('coverImage', file);
         }
 
         await axios.post('http://localhost:5000/api/books/add', data);
 
         navigate('/');
     } catch (err) {
         alert('Error adding book');
         console.error(err);
     }
    };

    return (
        <div className="container mt-4">
            <div className="card shadow p-4" style={{maxWidth: '600px', margin: '0 auto'}}>
                <h2 className="mb-3">Add New Book</h2>
                <form onSubmit={handleSubmit}>
                    <div className="mb-3">
                        <label className="form-label">Title</label>
                        <input type="text" name="title" className="form-control" onChange={handleChange} required />
                    </div>
                    <div className="mb-3">
                        <label className="form-label">Author</label>
                        <input type="text" name="author" className="form-control" onChange={handleChange} required />
                    </div>
                    <div className="mb-3">
                        <label className="form-label">ISBN</label>
                        <input type="text" name="isbn" className="form-control" onChange={handleChange} />
                    </div>
                    <div className="mb-3">
                        <label className="form-label">Cover Image</label>
                        <input type="file" className="form-control" onChange={handleFileChange} />
                    </div>
                    <button type="submit" className="btn btn-primary w-100">Add Book</button>
                </form>
            </div>
        </div>
    );
};

export default AddBook;

4. Wiring it up (App.jsx)

Routes in App.jsx.

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';
import BookList from './components/BookList';
import AddBook from './components/AddBook';

function App() {
  return (
    <BrowserRouter>
      <nav className="navbar navbar-expand-lg navbar-dark bg-dark">
        <div className="container">
            <Link className="navbar-brand" to="/">Library App</Link>
          <div>
            <Link className="btn btn-outline-light me-2" to="/">Home</Link>
            <Link className="btn btn-primary" to="/add">Add Book</Link>
          </div>
        </div>
      </nav>

      <Routes>
        <Route path="/" element={<BookList />} />
        <Route path="/add" element={<AddBook />} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;

5. Final UI & Integration Checklist

Key Focus Points for Integration

When connecting the React frontend to a Node/Express backend, keep these critical points in mind:

  • 1. CORS (Cross-Origin Resource Sharing):
    Backend (port 5000) must explicitly allow requests from frontend (port 5173). Ensure app.use(cors()) is present in Express - index.js.
  • 2. API Base URL:
    Hardcoding http://localhost:5000 works for dev, but in production, use environment variables (import.meta.env.VITE_API_URL).
  • 3. The `useEffect` Hook:
    API calls to fetch initial data (like `getAllBooks`) must go inside useEffect with an empty dependency array [] to prevent infinite loops.
  • 4. Handling File Uploads:
    Cannot send files as JSON. Use the FormData object and set the request header (Axios does this automatically when it sees FormData).
  • 5. Serving Static Images:
    The frontend `img src` points to the backend URL (e.g., `http://localhost:5000/uploads/image.jpg`). The backend must expose this folder using express.static('uploads').
