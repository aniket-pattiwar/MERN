Query Params (in URL) with Fetch & Axios API


 async function getUsers() {
  try {
    const response = await fetch(
      "https://api.example.com/users?name=Rahul&age=25"
    );

    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log(error);
  }
}
        

async function getUsers() {
  try {
    const response = await axios.get(
    "https://api.example.com/users", {
      params: {
        name: "Rahul",
        age: 25
      }
    });

    console.log(response.data);
  } catch (error) {
    console.log(error);
  }
}

Query Parameters are used to filter or modify the data returned by an API. They are added to the end of the URL after a question mark (?).

2. Folder Structure

A Layered Architecture.

backend/
├── config/         (Configuration & DB connection)
├── controllers/    (Request/Response logic)
├── models/         (Database Schemas)
├── repositories/   (Data Access Layer)
├── routes/         (API Endpoints)
└── index.js        (Entry Point)
3. Database Connection (`config/db.js`)

It handles the connection logic.


const connectDB = async () => {
  try {
    await mongoose.connect('mongodb://localhost:27017/libraryDB');
  } catch (err) {
    console.error('MongoDB Connection Failed:', err.message);
    process.exit(1);
  }
};
4. The Model (`models/Book.js`)

The schema for "Book" Collection.


const bookSchema = new mongoose.Schema({
  title: { type: String, required: true },
  author: { type: String, required: true },
  isbn: { type: String, unique: true },
  status: { type: String, default: 'Available' },
  coverImage: { type: String },
});

Implementing the API

The Repository Pattern & Logic

It separates the business logic (Controller) from the database logic (Repository).
1. The Repository (`repositories/bookRepository.js`)

It handles all direct interactions with the database.


async findAll() {
    return await Book.find();
}
2. The Controller (`controllers/bookController.js`)

The controller handles the HTTP request (req) and response (res), using the repository to get data.



exports.getAllBooks = async (req, res) => {
  try {
    const books = await bookRepository.findAll();
    res.json(books);
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
};
3. The Routes (`routes/bookRoutes.js`)

Map the URL endpoints to the controller functions.



router.get('/', bookController.getAllBooks);

Advanced Features & Wiring

1. File Uploads & Routes (`routes/bookRoutes.js`)

Update your routes file to handle file uploads using multer.


const multer = require('multer');
const upload = multer({ dest: 'uploads/' });

router.route('/')
  .post(bookController.createBook)
  .get(bookController.getAllBooks);

router.post('/upload', upload.single('coverImage'), (req, res) =>
  req.file
    ? res.json({ filePath: req.file.path })
    : res.status(400).json({ error: 'No file uploaded' })
);
2. The Entry Point (`index.js`)

Wire everything together, including Error Handling and serving static files. 


const cors = require('cors');
const app = express();
const PORT = 5000;

connectDB();

app.use(cors());
app.use(express.json());
app.use('/uploads', express.static('uploads'));

app.use('/api/books', bookRoutes);

app.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
