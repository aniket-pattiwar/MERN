State Management with Redux

The Problem: Prop Drilling

In a large React app, you often need to pass data from a top-level component to a deeply nested component. Passing this data through many intermediate components that don't need it is called "prop drilling." It makes code hard to read and maintain.

Example: Passing a Message

Imagine telling a secret to the first person in a long line, who then has to whisper it to the next, and so on, until it reaches the last person. The people in the middle don't care about the message, but they are forced to participate in passing it along.

The Solution: Redux Architecture

Redux solves prop drilling by creating a single, centralized "store" for your entire application's state. Any component can access or update this state without needing props passed down to it.

Example: A Central Bank

Instead of passing cash from person to person, everyone uses a central bank (the Store). If you want to change your balance, you fill out a deposit slip (an Action) and give it to the teller (the Reducer), who updates your account. Anyone with permission can check the balance at any time.

1. Installation
npm install @reduxjs/toolkit react-redux
2. Create a "Slice" (`features/cart/cartSlice.js`)

A "slice" automatically generates reducers and actions from a simple object.

import { createSlice } from '@reduxjs/toolkit';

const cartSlice = createSlice({
  name: 'cart',
  initialState: {
    items: 0
  },
  reducers: {
    addItem: (state) => {
      state.items += 1;
    },
    removeItem: (state) => {
      if (state.items > 0) {
        state.items -= 1;
      }
    }
  }
});

export const { addItem, removeItem } = cartSlice.actions;
export default cartSlice.reducer;

import { useSelector } from 'react-redux';

import { useDispatch } from 'react-redux';
import { addItem, removeItem } from './cartSlice';

function ProductPage() {
  const dispatch = useDispatch();

  return (
    <div>
      <button onClick={() => dispatch(addItem())}>
        Add Item

        Remove Item

    </div>
  );
}

export default ProductPage;

Runnable Code: Redux Toolkit Store, Slices & Dispatch Flow ReduxCounterApp.jsx
Copy & Run in React 
// ReduxCounterApp.jsx - Complete runnable Redux Toolkit App
import React from 'react';
import { configureStore, createSlice } from '@reduxjs/toolkit';
import { Provider, useSelector, useDispatch } from 'react-redux';

// 1. Create a Slice (State + Reducers + Actions bundled)
const cartSlice = createSlice({
  name: 'cart',
  initialState: { itemsCount: 0, totalAmount: 0 },
  reducers: {
    addItem: (state, action) => {
      state.itemsCount += 1;
      state.totalAmount += action.payload; // RTK allows intuitive mutating syntax via Immer!
    },
    removeItem: (state, action) => {
      if (state.itemsCount > 0) {
        state.itemsCount -= 1;
        state.totalAmount = Math.max(0, state.totalAmount - action.payload);
      }
    },
    clearCart: (state) => {
      state.itemsCount = 0;
      state.totalAmount = 0;
    }
  }
});

const { addItem, removeItem, clearCart } = cartSlice.actions;

// 2. Configure the Centralized Store
const store = configureStore({
  reducer: {
    cart: cartSlice.reducer
  }
});

// 3. Child Component consuming Redux State
function CartSummary() {
  const { itemsCount, totalAmount } = useSelector(state => state.cart);
  return (
    <div style={{ backgroundColor: '#f8fafc', padding: '16px', borderRadius: '8px', margin: '16px 0' }}>
      <h3>🛒 Shopping Cart State</h3>
      <p>Items in Cart: <strong>{itemsCount}</strong></p>
      <p>Total Balance: <strong>${totalAmount}</strong></p>
    </div>
  );
}

// 4. Child Component dispatching Redux Actions
function ProductList() {
  const dispatch = useDispatch();

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '8px' }}>
      <button onClick={() => dispatch(addItem(25))} style={{ padding: '8px', cursor: 'pointer' }}>
        Add Book ($25)
      </button>
      <button onClick={() => dispatch(addItem(75))} style={{ padding: '8px', cursor: 'pointer' }}>
        Add Headset ($75)
      </button>
      <button onClick={() => dispatch(removeItem(25))} style={{ padding: '8px', cursor: 'pointer' }}>
        Remove Item ($25)
      </button>
      <button onClick={() => dispatch(clearCart())} style={{ padding: '8px', cursor: 'pointer', backgroundColor: '#fee2e2' }}>
        Clear Cart
      </button>
    </div>
  );
}

// 5. Main Component wrapped in Redux Provider
export default function App() {
  return (
    <Provider store={store}>
      <div style={{ fontFamily: 'sans-serif', maxWidth: '400px', margin: '40px auto', padding: '20px', border: '1px solid #ccc', borderRadius: '12px' }}>
        <h2>⚛️ Redux Toolkit Live Demo</h2>
        <CartSummary />
        <ProductList />
      </div>
    </Provider>
  );
}
How it works: Demonstrates the complete Redux unidirectional data flow: UI Dispatches Action -> Reducer updates State in Central Store -> useSelector re-renders subscribed components.
Step-by-Step Instructions:
  1. Install Redux Toolkit and React-Redux: npm install @reduxjs/toolkit react-redux
  2. Paste this into src/App.jsx in your React project.
  3. Run: npm run dev and open your browser.
  4. Click the product buttons to dispatch actions to the central Redux Store!

Routing with useParams() hook

1. Advanced: Dynamic Routes

Dynamic routes allow you to match URL patterns, like a user ID.

import { useParams } from 'react-router-dom';

const UserProfile = () => {
  let { userId } = useParams(); // it reads the dynamic part of the URL
  return <h1>Profile for User ID: {userId}</h1>;
};

<Route path="/users/:userId" element={<UserProfile />} />
