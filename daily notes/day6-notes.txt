SECTION 1: CORE REACT CONCEPTS
==============================

1. SINGLE PAGE APPLICATIONS (SPA)
---------------------------------
What is it?
- A web app that loads ONE HTML page and dynamically updates content as users interact with it
- Feels like a desktop or mobile app - smooth and fast experience

How it's different from traditional websites:
- Traditional websites: Every click = full page reload from server
- SPA: Initial page load happens once, then only small JSON data is fetched to update parts of the page
- Result: Much faster and smoother user experience

Example: Gmail, Google Maps, Facebook - they don't reload the entire page when you click something


2. COMPONENT-ORIENTED ARCHITECTURE
-----------------------------------
What is it?
- React is all about breaking down your UI into small, reusable pieces called COMPONENTS
- Think of it like LEGO bricks - you build complex structures from simple, individual pieces

How it works:
- Each component is self-contained and can be reused
- Complex UIs are made by combining simple components together

Example structure:
- App Component (entire page)
  ├── Header Component (top navigation)
  ├── Sidebar Component (left side menu)
  └── Content Component (main area)

Benefits:
- Easy to manage because each component does one thing
- Can reuse components across different pages
- Easier to find and fix bugs


3. JSX, BABEL, AND WEBPACK
---------------------------
These three tools work together to make React possible:

JSX (JavaScript XML):
- A syntax that lets you write HTML-like code directly in JavaScript
- Makes UI code much more readable and intuitive
- Example: <h1>Hello World</h1> instead of createElement('h1', 'Hello World')

Babel:
- A JavaScript compiler (translator)
- Converts modern JavaScript and JSX into older JavaScript that ALL browsers understand
- Makes sure your code runs everywhere, even in older browsers

Webpack:
- A module bundler
- Takes all your files (JavaScript, CSS, images)
- Combines them into optimized files that are fast to download
- Makes sure dependencies are loaded in the right order

SECTION 2: REACT LAB - BUILDING YOUR FIRST APP
========================================

1. CHOOSING A TOOL: VITE vs CREATE REACT APP
---------------------------------------------
There are different tools to start a React project. Let's compare:

VITE (Modern - RECOMMENDED):
- Setup: npm create vite@latest
- Speed: EXTREMELY FAST development
- Hot Module Replacement (HMR): Near-instant updates while coding
- Status: Actively developed, recommended by React community
- Best for: New React projects, faster workflow

CREATE REACT APP (Legacy):
- Setup: npx create-react-app my-app
- Speed: Slower (bundles all code before showing anything)
- HMR: Slow updates
- Status: No longer recommended for new projects
- Issues: Tooling is outdated

DECISION: WE WILL USE VITE because it's faster, modern, and gives a better learning experience.


2. HOW TO CREATE YOUR FIRST REACT SPA WITH VITE
------------------------------------------------

STEP 1: Set up with Vite
Command: npm create vite@latest

Vite will ask you:
- Project name? >> Type: frontend
- Select a framework? >> Choose: React
- Select a variant? >> Choose: JavaScript

Then run:
  cd frontend
  npm install
  npm run dev

Your app is now running! But to test it on your phone on the same network:
  npm run dev -- --host


STEP 2: Create Reusable Components
-----------------------------------
You'll create three main components: Header, Content, Footer

FILE: src/Header.jsx
---
function Header(props) {
  return (
    <header style={{ backgroundColor: '#0d1117', color: 'white', padding: '1rem' }}>
      <h1>{props.title}</h1>
    </header>
  );
}
export default Header;
---

What's happening here?
- props.title: Gets a title passed from the parent component
- Style object: Inline styling with a dark background and white text
- Export: Makes this component available to other files

FILE: src/Content.jsx
---
function Content() {
  return (
    <main style={{ padding: '1rem' }}>
      <p>Welcome to MERN stack.</p>
    </main>
  );
}
---

What's happening here?
- Simple component that displays a message
- <main> tag is for semantic HTML (tells search engines this is the main content)

FILE: src/Footer.jsx
---
function Footer() {
  const currentYear = new Date().getFullYear();
  return (
    <footer style={{ padding: '1rem', borderTop: '1px solid #ccc' }}>
      <p>© {currentYear} FinTech Course. All Rights Reserved.</p>
    </footer>
  );
}
---

What's happening here?
- Gets current year automatically with new Date().getFullYear()
- Uses curly braces {} to insert JavaScript into JSX
- Shows how to dynamically update content


STEP 3: Assemble the App - Using Props
--------------------------------------
FILE: src/App.jsx
---
import './App.css';
import Header from './Header.jsx';

function App() {
  return (
    <div className="App">
      <Header title="MERN Stack for FinTech" />
    </div>
  );
}
---

What's happening here?
- Imports the Header component
- Passes a "title" prop to Header with value "MERN Stack for FinTech"
- Parent component (App) passes data DOWN to child component (Header)
- Header receives it as props.title and displays it

Example of Props:
- Props = properties passed from parent to child
- Like function arguments, but for components
- One-way flow: Parent → Child (not the other way around)


STEP 4: Add Styling
-------------------
FILE: src/App.css
---
.App {
  text-align: center;
}

main p {
  font-size: 1.2rem;
  color: #333;
}
---

How to use:
- Create CSS files alongside your components
- Import them in App.jsx: import './App.css';
- Use className instead of class in JSX (because class is a reserved word in JavaScript)

Example of what you'll see:
- Header with dark background and white title
- Main content with centered text
- Footer with copyright year (automatically updates next year!)


========================================
KEY TAKEAWAYS
========================================

1. SPAs are fast and smooth - like mobile apps
2. Components are reusable building blocks of your UI
3. Props let parent components pass data to child components
4. Vite is the modern, fast way to build React projects
5. Styling can be done inline or in separate CSS files
6. Always use className, not class, in JSX
7. Export components so other files can use them
8. Import components before you use them in other files
