The Context API

The Context API is React's built-in way to solve the "prop drilling" problem for global state. It allows you to share state across the entire app (or a part of it) without passing props down manually at every level.

Example: A Public Announcement System

Instead of whispering a message down a long line of people (prop drilling), the Context API is like a PA system for your building. A component can make an announcement (provide a value), and any other component in the building can listen to that announcement (consume the value) without anyone in between needing to be involved.

Advanced React

1. Using Context API for a Theme

Create a theme (light/dark mode) that any component can access.

`src/ThemeContext.js`

import React, { createContext, useState, useContext } from 'react';

const ThemeContext = createContext();

export const useTheme = () => useContext(ThemeContext);

export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(theme === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

Wrap app component in the provider in `src/main.jsx`:


import { ThemeProvider } from './ThemeContext';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <ThemeProvider>
      <App />
    </ThemeProvider>
  </React.StrictMode>
);
