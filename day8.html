React Hooks & Context API

Concept: React Hooks

Hooks are functions that let you "hook into" React state and lifecycle features from function components. They allow you to use state and other React features without writing a class.

  • `useState`: Lets you add state to a functional component.
  • `useEffect`: Lets you perform side effects in your components, such as fetching data, subscribing to events, or manually changing the DOM.
Real-World Analogy: A Personal Whiteboard

Think of `useState` as giving a component its own personal whiteboard. It can write down information (`state`), read it, and update it. When the information on the whiteboard changes, the component knows it needs to re-render to show the new information.

Concept: The Context API

The Context API is React's built-in way to solve the "prop drilling" problem for global state. It allows you to share state across the entire app (or a part of it) without passing props down manually at every level.

Real-World Analogy: A Public Announcement System

Instead of whispering a message down a long line of people (prop drilling), the Context API is like a PA system for your building. A component can make an announcement (provide a value), and any other component in the building can listen to that announcement (consume the value) without anyone in between needing to be involved.

Lab 14: Refactoring with Hooks & Context

1. Refactoring a Class Component to use `useState`

Below is a simple counter, first as a class component and then as a functional component using the `useState` hook.

Before (Class Component)

import React from 'react';

class Counter extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }

  render() {
    return (
      <div>
        <p>Count: {this.state.count}</p>
        <button onClick={() => this.setState({ count: this.state.count + 1 })}>
          Increment
        </button>
      </div>
    );
  }
}

After (Functional Component with Hook)

import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}
2. Using Context API for a Theme

Let's create a theme (light/dark mode) that any component can access.

`src/ThemeContext.js`

import React, { createContext, useState, useContext } from 'react';

const ThemeContext = createContext();

export const useTheme = () => useContext(ThemeContext);

export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(theme === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

Wrap your app in the provider in `src/main.jsx`:

// ... other imports
import { ThemeProvider } from './ThemeContext';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <ThemeProvider>
      <App />
    </ThemeProvider>
  </React.StrictMode>
);

// A mock payment component
function PaymentButton({ amount }) {
