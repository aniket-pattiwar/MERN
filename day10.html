Prop Drilling vs Context API

PART 1: PROP DRILLING VERSION

What is Prop Drilling?

Prop drilling occurs when you need to pass data from a top-level component down to a deeply nested component through multiple intermediate components that don't actually need that data. This makes the code harder to read, maintain, and refactor.

In this example, we'll store the theme state in the App component and pass it down through props to the Navbar and then to each page component.

App.jsx - Root Component with Theme State

The App component manages the theme state and passes it down to child components. Notice how we have to pass theme and toggleTheme to Navbar, which then passes theme to the pages.

import { useState } from 'react';
import { BrowserRouter as Router, Routes, Route } from 'react-router-dom';
import Navbar from './components/Navbar';
import Home from './components/Home';
import About from './components/About';
import Login from './components/Login';

function App() {
  // Theme state stored at the top level
  const [theme, setTheme] = useState('light');

  // Function to toggle theme
  const toggleTheme = () => {
    setTheme(theme === 'light' ? 'dark' : 'light');
  };

  // Console log to show re-renders
  console.log('App re-rendered');

  return (
    <Router>
      <div className={`app ${theme}`}>
        {/* Pass theme and toggleTheme to Navbar */}
        <Navbar theme={theme} toggleTheme={toggleTheme} />
        <Routes>
          {/* Pass theme to each page component */}
          <Route path="/" element={<Home theme={theme} />} />
          <Route path="/about" element={<About theme={theme} />} />
          <Route path="/login" element={<Login theme={theme} />} />
        </Routes>
      </div>
    </Router>
  );
}

export default App;

Navbar.jsx - Receives Props and Passes to Pages

The Navbar component receives theme and toggleTheme as props. It uses toggleTheme for the button but doesn't need theme itself. However, it still has to receive and potentially pass theme down.

import { Link } from 'react-router-dom';

function Navbar({ theme, toggleTheme }) {
  // Console log to show re-renders
  console.log('Navbar re-rendered');

  return (
    <nav className={`navbar navbar-expand-lg ${theme === 'dark' ? 'navbar-dark bg-dark' : 'navbar-light bg-light'}`}>
      <div className="container">
        <Link className="navbar-brand" to="/">My App</Link>
        <div className="navbar-nav">
          <Link className="nav-link" to="/">Home</Link>
          <Link className="nav-link" to="/about">About</Link>
          <Link className="nav-link" to="/login">Login</Link>
        </div>
        <button className="btn btn-outline-primary ms-auto" onClick={toggleTheme}>
          Toggle {theme === 'light' ? 'Dark' : 'Light'} Theme
        </button>
      </div>
    </nav>
  );
}

export default Navbar;

PART 2: CONTEXT API VERSION (REFACTOR)

What is Context API?

React Context API allows you to share data (state) across the component tree without having to pass props down manually at every level. It's perfect for global app data like themes, user authentication, or language preferences.

We'll create a ThemeContext and ThemeProvider to manage the theme state globally.

ThemeContext.jsx - Create the Context

import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext();

export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(theme === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

export const useTheme = () => useContext(ThemeContext);

App.jsx - Simplified with Context

App.jsx is much cleaner. No more prop drilling!

import { BrowserRouter, Routes, Route } from 'react-router-dom';
import { ThemeProvider } from './ThemeContext';
import Navbar from './Navbar';
import Home from './Home';
import About from './About';

function App() {
  return (
    <ThemeProvider>
      <BrowserRouter>
        <Navbar />
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
        </Routes>
      </BrowserRouter>
    </ThemeProvider>
  );
}

export default App;

Navbar.jsx - Using Context

Navbar now uses the useTheme hook to access theme and toggleTheme directly from context.

import { useTheme } from './ThemeContext';

function Navbar() {
  const { theme, toggleTheme } = useTheme();

  return (
    <div>
      <button onClick={toggleTheme}>
        Switch to {theme === 'light' ? 'Dark' : 'Light'}
      </button>
    </div>
  );
}

export default Navbar;

PART 3: COMPARISON

Difference Between Prop Drilling and Context API

Prop Drilling:
  • Data is passed through props at every level
  • Intermediate components receive props they don't need
  • Code becomes cluttered and hard to maintain
  • Adding new components requires updating the prop chain
  • Good for simple, shallow component trees
Context API:
  • Data is available globally to all components in the tree
  • Components only receive what they need via hooks
  • Cleaner, more maintainable code
  • New components can access data without prop changes
  • Best for app-wide state like themes, auth, language

When NOT to Use Context

Context is great for global app state, but don't overuse it:

  • Simple apps: If your app is small and the component tree is shallow, prop drilling might be simpler
  • Component-specific state: Use local state or props for data only used by one component
  • Frequent updates: Context can cause unnecessary re-renders if not optimized
  • Complex state logic: Consider state management libraries like Redux for very complex apps

PART 4: BONUS FEATURES

Persist Theme in localStorage

As shown in the ThemeProvider, we can persist the theme choice so it survives page refreshes.

// In ThemeProvider
const [theme, setTheme] = useState(() => {
  const savedTheme = localStorage.getItem('theme');
  return savedTheme || 'light';
});

// Save whenever theme changes
useEffect(() => {
  localStorage.setItem('theme', theme);
}, [theme]);

Complete Example with All Features

Here's the complete ThemeContext with all bonus features:

import { createContext, useContext, useState, useEffect } from 'react';

const ThemeContext = createContext();

export const useTheme = () => {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme must be used within a ThemeProvider');
  }
  return context;
};

export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState(() => {
    const saved = localStorage.getItem('theme');
    return saved || 'light';
  });

  const toggleTheme = () => {
    setTheme(prev => {
      const newTheme = prev === 'light' ? 'dark' : 'light';
      localStorage.setItem('theme', newTheme);
      return newTheme;
    });
  };

  useEffect(() => {
    document.body.className = theme;
  }, [theme]);

  const value = {
    theme,
    toggleTheme,
    isDark: theme === 'dark',
    isLight: theme === 'light'
  };

  return (
    <ThemeContext.Provider value={value}>
      {children}
    </ThemeContext.Provider>
  );
};
