The Event Loop & Asynchronous Lab

What is the Event Loop?

Node.js uses a Single-Threaded Event Loop

Eg.Circular conveyor belt in a factory. It keeps checking for new tasks and processes them without waiting for long tasks to finish,

  1. Input: Tasks come in (like HTTP requests)
  2. Stack: Tasks are processed one by one
  3. Waiting: Long tasks are sent to background
  4. Queue: Completed tasks wait their turn
  5. Loop: When stack is empty, queue tasks run
1. Understanding Asynchronous Code

Node.js is non-blocking. It doesn't wait for timers to finish before moving to the next line. 


console.log("Start");

setTimeout(() => {
  console.log("After 2 seconds");
}, 2000);

console.log("End");

Working with Files (fs)

1. The File System (fs) Module

Node.js has a built-in module called fs to work with files.

Why 'utf8'?
Files are stored as 0s and 1s (Binary).
  • Without 'utf8': You get a Buffer (e.g., <Buffer 48 65...>).
  • With 'utf8': Node converts it to readable Text.
2. Write and Read a File
Block 1: Import (Setup)

fs module.

const fs = require('fs');

Block 2: Write (The Action)

fs.writeFile to create the file.

Block 3: Read (The Verification)

fs.readFile to read the file.

2. Testing with Jest

Testing is crucial for reliability.
Install Jest: npm install --save-dev jest.

Test file 

const math = require('./math');

test('adds 1 + 2 to equal 3', () => {
  expect(math.add(1, 2)).toBe(3);
});

test('subtracts 5 - 2 to equal 3', () => {
    expect(math.subtract(5, 2)).toBe(3);
});

Add a "test" script to `package.json` file: `"test": "jest"`. Run tests with `npm test`.
